# Cinema API — ДЗ №2

REST API кінотеатру на NestJS, TypeORM і PostgreSQL. API працює з фільмами, залами, сеансами й бронюваннями.

## Локальний запуск

Потрібні Node.js 24, npm і Docker Compose.

1. Встановіть залежності командою `npm ci`.
2. Створіть `.env` на основі `.env.example` і за потреби змініть значення.

   ```dotenv
   PORT=3000
   DB_HOST=127.0.0.1
   DB_PORT=5432
   DB_USER=cinema
   DB_PASSWORD=cinema_dev_password
   DB_NAME=cinema
   ```

3. Запустіть PostgreSQL командою `docker compose up -d --wait`.
4. Застосуйте міграції командою `npm run migration:run`.
5. За бажанням додайте демонстраційні дані командою `npm run seed`. Повторний запуск не створює дублікати.
6. Запустіть API в режимі розробки командою `npm run start:dev`.

Swagger доступний за адресою [http://localhost:3000/docs](http://localhost:3000/docs). Для ручної перевірки використайте `requests.http` у VS Code з розширенням REST Client. Виконуйте запити згори вниз на свіжій базі.

## Поведінка API

- `GET /showings` приймає `filmId`, `date` у форматі `YYYY-MM-DD` за UTC, `page` (типово 1), `limit` (від 1 до 100, типово 20) і `sort` (`asc` або `desc`, типово `asc`). При однаковому часі початку сеанси впорядковуються за ID за зростанням. Відповідь містить `items`, `total`, `page` і `limit`.
- `POST /showings/:id/bookings` зберігає бронювання та всі його місця в одній транзакції. Повторне бронювання місця для того самого сеансу повертає 409.
- `DELETE /bookings/:id` звільняє місця через каскадне видалення в базі. Видалення фільму чи залу, на який посилається сеанс, повертає 409.
- Ціни вказуються в копійках. HTTP-помилки мають поля `statusCode`, `message` та `path`.

## Перевірка

Запустіть `npm test` після застосування міграцій до локальної бази. Тест створює власні записи і прибирає їх після виконання. Він перевіряє маршрути, валідацію, фільтрацію і пагінацію, відкат після конфлікту, одночасне бронювання та звільнення місць.

На тестовій базі можна перевірити оборотність міграції командами `npm run migration:revert` і `npm run migration:run`. Відкат початкової міграції видаляє таблиці застосунку та їхні дані.
